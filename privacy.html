Что это за программа

Pipeline Combiner — настольное приложение, которое запускается на компьютере пользователя. Оно собирает видео из сценария и по команде пользователя загружает готовое видео на его собственный канал YouTube.

Какие данные Google используются

Приложение запрашивает у Google разрешения youtube.upload (загрузка видео на канал пользователя) и youtube.readonly (чтение названия и идентификатора канала, чтобы показать их в программе). Другие данные аккаунта Google приложение не запрашивает и не читает.

Где хранятся данные

Токен доступа к каналу хранится только на компьютере пользователя в папке программы. Он не передаётся разработчику, третьим лицам или на какие-либо серверы, кроме серверов Google (API YouTube) при загрузке видео. Названия, описания и теги роликов создаются на компьютере пользователя и отправляются только в YouTube.

Передача третьим лицам

Приложение не продаёт, не передаёт и не использует данные Google-аккаунта пользователя ни для каких целей, кроме загрузки видео на его канал. Данные не используются для рекламы и не передаются рекламным сетям.

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions или удалив файл токена из папки программы.

Соответствие политике Google

Использование данных, полученных из Google API, соответствует Google API Services User Data Policy, включая требования ограниченного использования (Limited Use).

Privacy Policy

Last updated: September 4, 2026

What the app is

Pipeline Combiner is a desktop application that runs on the user's own computer. It assembles a video from a script and, on the user's command, uploads the finished video to the user's own YouTube channel.

Google data used

The app requests the Google permissions youtube.upload (upload videos to the user's channel) and youtube.readonly (read the channel title and id to display them in the app). No other Google account data is requested or read.

Storage

The channel access token is stored only on the user's computer, inside the application folder. It is never sent to the developer, to third parties or to any server other than Google's YouTube API during the upload. Video titles, descriptions and tags are generated on the user's computer and sent only to YouTube.

Sharing

The app does not sell, share or use Google account data for any purpose other than uploading videos to the user's channel. Data is not used for advertising and is not shared with ad networks.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or by deleting the token file from the application folder.

Google policy compliance

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
